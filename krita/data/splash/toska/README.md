# Toska splash artwork

`toska-splash.png` (the splash painting) and the logo embedded in `banner.svg` (made from
`creative-agent/docs/branding/toska-logo.png`) are artwork owned by the artist, licence to be decided. No licence
is granted for them by this repository's code licences; ask the artist before reusing them.

`make_banner.py` is code (GPL-3.0-or-later) and remakes `banner.svg` from the logo. Only one size of the painting
exists (1774 x 887); a larger version replaces `toska-splash.png` later under the same alias. Both PNGs carry an sRGB
chunk, as the artist's sources do. See AGENT-FORK.md, "Product name: Toska", "Splash screen".
